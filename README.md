# Prologg.org in Eleventy, Astro and React

This repository contains three versions of the same Prologg web page, each built with a different framework. The goal is to compare how Eleventy, Astro and React handle layouts, components, content and styling, and to find out which framework fits Prologg best.

Each version contains the same page: navigation, hero, one content section and footer, with the same Prologg styling and content.

## Live demo's

| Framework | Live site |
|---|---|

## Getting started

Each branch has its own README with full instructions. In short:

```bash
git clone https://github.com/ahlamad/frameworks.git
cd frameworks
git checkout 
npm install
npm run dev   # Eleventy: npm start
npm run build
```
